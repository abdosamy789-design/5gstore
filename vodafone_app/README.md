# فودافون ريد — متجر الباقات + بوابة دفع

تطبيق بايثون (Flask) لبيع وتفعيل باقات فودافون ريد مع بوابة دفع فودافون كاش عبر تطبيق موبايل.

## المميزات

1. **واجهة العميل**
   - تسجيل بيانات واضحة (الاسم + رقم فودافون مصر 010)
   - التحقق إن الرقم تابع لفودافون مصر
   - اختيار باقة من الباقات اللي المدير بيحددها
   - عرض رقم فودافون كاش للتحويل
   - إدخال رقم اللي اتحوّل منه لتأكيد الدفع

2. **بوابة الدفع**
   - لينك webhook للتطبيق الموبايل
   - استقبال رسالة SMS كاملة من فودافون كاش
   - استخراج رقم المرسل والمبلغ ومطابقة الطلب تلقائياً

3. **لوحة المدير**
   - يوزر وباسورد
   - صفحة بيانات كل الطلبات
   - إدارة الباقات
   - إعداد رقم الاستلام وتوكن الموبايل
   - تأكيد/تنفيذ الطلبات يدوياً

## التشغيل

```bash
cd vodafone_app
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python run.py
```

- الموقع: http://127.0.0.1:5000
- المدير: http://127.0.0.1:5000/admin/login
  - يوزر: `admin`
  - باسورد: `admin123`

غيّر القيم من ملف `.env` أو من صفحة الإعدادات بعد الدخول.

## ربط تطبيق الموبايل

في إعدادات المدير هتلاقي لينك بوابة الدفع. ضيفه في الأبلكيشن:

```
POST /api/payment/webhook
Header: X-Webhook-Token: <التوكن من الإعدادات>
Content-Type: application/json

{
  "message": "نص رسالة فودافون كاش كاملة",
  "sender": "010xxxxxxxx",
  "amount": 100
}
```

لما الرسالة توصل والمبلغ/الرقم يطابقوا طلب العميل، الحالة بتتغير تلقائياً لـ **مدفوع**.

## ملاحظة عن التحقق من فودافون

التحقق من أن الرقم فودافون مصر يتم عبر نطاق الترقيم الرسمي (010). الربط الحي مع أنظمة فودافون الداخلية يحتاج اشتراك API تجاري من فودافون مصر.
